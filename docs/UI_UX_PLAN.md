## Принятые решения

- Local state и системный `hosts` — два разных уровня сохранения.
- Local state сохраняется автоматически и не требует отдельной кнопки.
- «Сохранить в hosts» остаётся явным ручным действием с preview.
- Предупреждение при закрытии относится только к неприменённому `hosts`, а не к
  риску потери local state.
